玩法说明

1. 热力值从哪来

小游戏得分兑换（幸存者每天上限 1200）、农场买卖、每日签到（100 起，连续签到加 20，最多 200）、管理员偶尔发放。

2. 怎么交易

每天 12:00 - 18:00 可以买入（做多）和做空；平仓不受时段限制。买入是价格涨了赚、跌了亏；做空反过来。每笔开仓 / 平仓都会按名义价值推动价格，金额越大涨跌越明显。

3. 杠杆与冷却

1x / 2x / 4x / 5x / 10x。杠杆越高，能撬动的仓位越大，但平仓冷却越长：1x 1 天、2x 36 小时、4x 2 天、5x 60 小时、10x 3 天。

4. 强平与破产

账户权益（保证金 + 浮动盈亏）跌到保证金的 50% 时自动强制结算，退回剩余权益。热力值归零就是破产清算，靠明天签到翻身。

5. 注意

这是社团娱乐用的模拟盘，不涉及任何真实货币。行情由服务器随机生成并受大家交易冲击，管理员可以手动修正异常价格。
